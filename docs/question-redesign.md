# 設問リニューアル案（ハンターハンター世界観への寄せ）

現行30問は「一般的な性格診断」の言い回しになっており、水見式という題材の面白さが
設問文に出ていない。原作の世界観に寄せた設問へ差し替えるための、原作確認メモと設問案。

**決定：案A（リッカートのまま設問文を原作の場面に置き換える）を採用し、3節のドラフトを
`data/nen-shindan-questions.json` に反映済み。** 案B・案Cは不採用だが、将来5択形式を
検討する際の出発点として記録を残す。

## 1. 原作確認メモ

### 1.1 六性図（隣接関係）

```
        強化系
    放出系   変化系
    操作系   具現化系
        特質系
```

- 隣り合う系統ほど習得しやすい（自系統100% / 隣接80% / 2つ離れ60% / 正反対40%）
- 強化系の正反対が特質系。特質系は他5系統から後天的に変化することもある稀少枠
- 現行実装の `hexagonOrder` / `adjacency` / `compatibility` は上記と一致しており、修正不要

### 1.2 系統ごとの性格傾向（原作で語られる水見式の説明に基づく）

| 系統 | 性格傾向 | 水見式での変化 |
| --- | --- | --- |
| 強化系 | 単純・一途（意固地） | グラスの水の量が増える |
| 変化系 | 気まぐれ・ウソつき | 水の味が変わる |
| 具現化系 | 神経質・多感 | 水に不純物が現れる |
| 特質系 | 個人主義・カリスマ性 | 上記以外の予測不能な変化 |
| 操作系 | 理屈屋・マイペース | 浮かべた葉が動く |
| 放出系 | 短気・大雑把 | 水の色が変わる |

現行の `systems[].description` はこの傾向を独自の言葉で書き直したものになっており、
方針としては維持でよい。

### 1.3 設問の舞台として使える原作の状況

物語の各編から、「その場に自分がいたらどうするか」を問える場面を洗い出した。

- **ハンター試験編**: 行き先も距離も知らされない長距離走（一次）／料理を作らされる試験（二次）／
  制限時間つきの塔攻略と、道中で仕掛けられる一対一の勝負（三次）／
  無人島でのプレート争奪サバイバル（四次）／受験者同士の最終戦（五次）
- **天空闘技場編**: 階を上がるほど強くなる勝ち抜き戦、念の基礎（纒・絶・練・発）の修行
- **ヨークシン編**: 巨大オークション、情報屋との駆け引き、盗賊集団との遭遇、念能力の条件と誓約
- **G.I.編**: カードを集めるゲーム世界、限られた枠に何を残すかの取捨選択、
  プレイヤー同士の交渉・カード交換
- **キメラアント編**: 圧倒的な格上との遭遇、仲間の役割分担、逃げるか挑むかの判断
- **暗黒大陸編**: 未知の脅威への航海、船内の派閥・護衛依頼

### 1.4 権利面の方針（`docs/requirements.md` 8節に準拠）

- 台詞の転載はしない。場面は自分の言葉で書き直す
- キャラクター名は設問に出さない（「試験官」「対戦相手」「同期の受験者」などの役割名で書く）
- 固有名詞は舞台・用語レベル（ハンター試験、水見式、纒・絶・練・発、誓約と制約など）にとどめる
- 引き続き「非公式ファンメイド」の明記を維持

## 2. 出題形式の選択肢

例に挙げられた「ハンター試験に持っていくものは？」は5択のシチュエーション問題であり、
現行の5段階リッカートとは形式が異なる。実装への影響が大きく異なるため、3案を比較する。

### 案A：リッカートのまま、設問文を原作の場面に置き換える（採用）

> 一次試験。行き先も距離も知らされないまま走り続けることになった。
> **ペース配分を考えるより、先頭の背中に食らいついていたい。**
> （まったく当てはまらない〜とても当てはまる）

- 変更点は `data/nen-shindan-questions.json` の `questions[].text` のみ
- スコアリング、特質系判定（低関与型・矛盾型の閾値）、既存テスト、チームURLはすべて無傷
- 5段階の濃淡が残るため、これまでモンテカルロ検証で調整した閾値がそのまま通用する
- 世界観は十分に出る一方、「クイズを解いている」感は案Bに劣る

### 案B：5択のシチュエーション問題（選択肢＝系統）に作り替える

> **ハンター試験に一つだけ持ち込むなら？**
> 1. 使い込んだ自前の装備一式（具現化系）
> 2. 何も持たない。体一つで十分（強化系）
> 3. 変装と小細工の道具（変化系）
> 4. 現地で使える情報屋の連絡先（操作系）
> 5. 迷ったら全部。重さは走りながら考える（放出系）

- 世界観の主張は最も強く、「診断」より「クイズ」として遊べる
- 一方でスコアリングの作り直しと再検証が必要
  - 1問1票になり濃淡が消えるため、スコア分布が現行より両極化する
  - 特質系の閾値（低関与型 `max<=45` / 矛盾型 `second>=60, gap<=10`）は必ず再調整が要る
    （`docs/requirements.md` 11節で積み上げたモンテカルロ検証をやり直す）
  - 隣接系統への0.3の滲み出しをどう扱うか（選択肢に副系統の重みを持たせるか）も再設計
- さらに、5択の選択肢を系統に割り当てる作業には恣意性が出やすい。
  「性格として自分に近いもの」ではなく「内容として好きなもの」で選ばれ、
  診断精度が落ちるリスクがある
- 設問数は30問だと選択肢150個の作文が必要になるため、15〜20問に減らすのが現実的

### 案C：案Aを土台に、数問だけ5択問題を混ぜる

- 冒頭2〜3問を「持ち物は？」のような掴みの5択にし、残りをリッカートにする
- 5択部分だけ配点を別扱いにする必要があり、スコアリングは案Bと同程度に複雑になる
- 体験としては良いが、実装コストと検証コストは案Aより明確に大きい

**推奨は案A。** 個性の付与という目的は設問文の書き換えでほぼ達成でき、
すでに検証済みの判定ロジックを触らずに済む。5択への作り替え（案B）を選ぶ場合は、
スコアリング再設計とモンテカルロ再検証を含む別作業として進めたい。

## 4. 案B：5択問題にする場合のサンプル

案Bを選ぶ場合の雰囲気サンプル（8問分）。カッコ内は対応する系統。

1. **ハンター試験に一つだけ持ち込むなら？**
   体一つ、装備は現地で何とかする（強化）／変装と小細工の道具（変化）／
   点検済みの自前の装備一式（具現化）／現地で使える情報屋の連絡先（操作）／
   迷ったので全部。重さは走りながら考える（放出）
2. **一次試験、行き先も距離も分からない長距離走。あなたは？**
   先頭に食らいつく（強化）／わざと中位に紛れて周りを観察する（変化）／
   歩数とペースを計算して配分する（具現化）／脱落しそうな受験者から情報を引き出す（操作）／
   考えずに飛ばす。持てば勝ち（放出）
3. **塔の攻略、道中で一対一の勝負を挑まれた。**
   正面から受けて立つ（強化）／勝負の条件そのものを書き換える提案をする（変化）／
   ルールの穴を確認してから受ける（具現化）／相手に断らせるよう仕向ける（操作）／
   話が終わる前に仕掛ける（放出）
4. **無人島のプレート争奪戦。狙いは？**
   正面から本人に挑む（強化）／別人になりすまして近づく（変化）／
   罠を設置して待つ（具現化）／他の受験者を焚きつけて奪わせる（操作）／
   手当たり次第に襲って数を集める（放出）
5. **念を覚えるなら、まず何から？**
   毎日「纒」を絶やさない反復（強化）／気分に合わせて色々試す（変化）／
   教本どおりに手順を記録しながら（具現化）／理屈を理解してから体を動かす（操作）／
   「練」で最大出力を出してみる（放出）
6. **自分の念能力に付けるなら、どんな制約？**
   一度使うと決めたら引かない（強化）／使うたびに効果が変わる（変化）／
   条件を細かく積み上げるほど強くなる（具現化）／相手が同意したときだけ発動する（操作）／
   時間制限つきで全力を出し切る（放出）
7. **オークション会場、狙いの品を落札するには？**
   正攻法で金を稼いで買う（強化）／偽物とすり替える（変化）／
   出品履歴を全部洗って相場を読む（具現化）／出品者と裏で話をつける（操作）／
   会場に乗り込んで直談判する（放出）
8. **明らかな格上と鉢合わせた。**
   勝てなくても一発入れて帰る（強化）／敵意がないふりでやり過ごす（変化）／
   逃走経路と地形を確認してから動く（具現化）／仲間に合図を送って囲む（操作）／
   全力で逃げる。生き残れば次がある（放出）

30問に増やす場合、選択肢は150個必要になる。案Bを採用するなら15〜20問に減らし、
スコアリングを1問1票ベースに作り替えたうえで、判定閾値を再検証する。

## 5. 付随して見直したい点（案Aでも同時にできる範囲）

- **リッカートのラベル**：「まったく当てはまらない〜とても当てはまる」は事務的。
  「絶対にちがう／たぶんちがう／どちらともいえない／たぶんそう／まさに自分だ」など、
  少しくだけた言い回しにできる（`likert.labels` の変更のみ）
- **診断開始画面のコピー**：水見式（グラスに水を張り、葉を浮かべ、練を行う）の
  導入文を1〜2行足すと、設問の世界観と地続きになる
- **設問中の用語**：纒・絶・練・発・硬・誓約と制約といった用語を設問に出す場合、
  未読の人向けに軽い注釈を出すか、用語を使わない言い回しに寄せるかを決めておきたい
